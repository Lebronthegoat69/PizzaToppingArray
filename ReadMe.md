# Pizza Topping Array

## Project Description

This Java program demonstrates the use of arrays, classes, constructors, inheritance, and `toString()` methods. The program creates regular pizzas and delivery pizzas using a String array to store pizza toppings.

The Pizza class calculates the pizza price based on the number of toppings. The DeliveryPizza class inherits from Pizza and adds a delivery address and delivery fee.

## How to Run
1. Open the project in IntelliJ IDEA.
2. Open `Main.java`.
3. Run the `main()` method.
4. View the pizza information in the console.
 Program Features
* Uses a String array to store pizza toppings.
* Calculates pizza prices based on the number of toppings.
* Uses inheritance with the DeliveryPizza subclass.
* Calculates delivery fees based on the pizza price.
* Displays pizza information using `toString()`.
